# 春日部駅高架化による短縮効果分析プログラム

## 📋 概要

このプログラムは、春日部駅における高架化（線路の立体交差化）による**徒歩短縮時間**の効果を GIS を使用して定量的に計算します。

## ✨ 機能

### 1. ランダム出発点生成
- 春日部駅から半径1km の円周上にランダムに100個の出発点を生成

### 2. 最短経路計算（OSMnx 使用）
- OpenStreetMap の道路ネットワークから**最短経路を自動計算**
- 各出発点から7つの通り抜けポイントまでの最短距離を記録

### 3. 高架化エリアの定義
- 近藤葬儀式場 ～ 5998 Kasukabe を結ぶ線路沿い（30mバッファ）
- この領域を通る経路と迂回経路の距離差を計算

### 4. 短縮時間の計算
- **歩行速度4km/h** で換算
- 短縮できる徒歩時間（分）を算出

### 5. 統計分析
- 100サンプルの平均短縮時間を計算
- 中央値、標準偏差、最小値、最大値も出力

## 🚀 使用方法

### 必要環境
- Python 3.8 以上
- 各種 GIS ライブラリ

### セットアップ

```bash
# 1. 依存ライブラリをインストール
pip install -r requirements.txt

# 2. プログラムを実行
python kasukabe_shorten_effect.py
```

## 📝 注意事項

- 初回実行時は OpenStreetMap からデータをダウンロードするため、**10～30分程度かかる場合があります**
- インターネット接続が必要です
- 大量のデータ処理を行うため、**メモリは 4GB 以上**推奨

## 🤝 トラブルシューティング

**Q: エラー「No data returned by API」が出た**
- A: インターネット接続を確認し、再度実行してください

**Q: 実行が遅い**
- A: 初回実行は特に遅くなります。コンソール出力で進捗を確認してください

**Q: メモリ不足エラー**
- A: メモリを確保するか、SAMPLE_SIZE を減らして実行してください
